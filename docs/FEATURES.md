# 功能清單 — SoundFlow

優先：P0＝第一版必備、P1＝下一步、P2＝之後。「倬確認」欄空白＝建議（未確認），請倬勾選或刪除。
語音動作欄與 `docs/AGENT_API.md`、`docs/agent-manifest.json` 一致（2026-10-23 規劃版，共 21 個動作）。

倬 2026-10-23 已確認整份清單（含所有建議項目）與以下方向：
- 長期封存＝**Google Drive**；暫存區採**兩層**（新檔先放 Supabase、舊檔自動搬到 Drive）
- YouTube 抽音軌在 **N100 拉斐爾主機**執行（24 小時開機）
- 操作方式參考 **Spotify、YouTube Music**（外觀不照抄）
- 原始需求：桌面播放器小工具（播放、下一首、單曲循環、切換播放清單、倍速）、Podcast／YouTube 兩個分頁、YouTube 分享進來自動抽音軌、標題抓原標題可改名、其他標竿播放器功能

## 不做的項目

- **直接串流 YouTube（不抽音軌）**：違反 YouTube 條款且很不穩定，網址會過期；改成抽一次存起來
- **影片畫面**：只做音訊
- **等化器、歌詞、社群分享、推薦演算法**：內容是 Podcast 與演講類，用不到
- **AI 功能**：目前沒有需要 AI 判斷的地方；之後若要「AI 摘要這集」再評估
- **pCloud**：倬已選 Google Drive；pCloud 直連網址的限制未驗證
- **Supabase 付費方案**：兩層儲存已解決容量問題
- **在電腦 A 跑 YouTube 轉檔**：電腦關機時會卡住，改在 N100
- **NotebookLM 單字卡**：新知網站已經有，SoundFlow 只管音訊

## 倬已決定的細節（2026-10-23）
