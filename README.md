# SoundFlow

倬的手機音訊播放器：在一個 App 裡聽「新知雷達」產生的 NotebookLM Podcast，以及從 YouTube 分享進來的影片音檔。手機桌面的小工具可以直接播放、切換清單、調倍速，不用再打開網頁或 YouTube。

> 目前版本 **v0.3.0**：可以登入、看新知雷達的 Podcast 列表並在背景播放；YouTube 分享、桌面小工具還在開發中。

## 安裝

1. 手機打開 GitHub 的 `latest` 預先發行版頁面，下載 `SoundFlow-LAB-latest.apk`（新功能先裝 LAB 版；正式版是 `SoundFlow-latest.apk`）
2. 第一次安裝時允許「安裝未知應用程式」
3. LAB 版與正式版可以同時安裝，名稱分別是「SoundFlow LAB」與「SoundFlow」

## 現在能用的功能

- **登入**：第一次打開「音檔」分頁會看到登入卡片 → 輸入信箱 → 按「寄驗證碼」→ 收信後輸入 6 位數 → 登入。之後會一直保持登入（換手機或重裝要重新登入）
  - 只有加進白名單的信箱看得到資料；沒收到信請看垃圾郵件匣，60 秒後可以重寄
- **Podcast 列表**：新知雷達按「送進 NotebookLM」產生的 Podcast 會自動出現，兩欄卡片顯示來源、長度、日期；往下拉重新整理；沒網路時顯示上次的列表
- **帳號**：設定 →「帳號與雲端」可以按「測試」確認連線，或登出
- **播放**：點卡片就從那集開始播整個列表；再點正在播的那集是暫停／繼續
  - 第一次播放會問「通知」權限：允許後通知列與鎖定畫面才有播放控制（不允許也能播）
  - 關螢幕、切到別的 App 會繼續播；藍牙耳機按鍵可以播放／暫停／切歌；來電或拔耳機自動暫停
  - 底部的迷你播放列：播放／暫停、下一首；點一下打開全螢幕播放頁
- **全螢幕播放頁**：拖曳進度、倒轉 15 秒、快轉 30 秒、上一首／下一首
  - **倍速**：0.5～3 倍，常用值一鍵選；Podcast 與 YouTube 各自記住（Podcast 預設 1.3 倍）
  - **循環**：點一下在「關 → 清單 → 單曲」之間切換；下方可開關隨機播放
  - **睡眠計時**：15／30／45／60／90 分鐘或「本集結束」，時間到前音量慢慢變小再停
  - **跳過靜音**：自動略過沒有聲音的片段
  - 下方列出接下來的 3 集
- **記住進度**：聽到一半下次會從中斷處繼續（往回 3 秒）；播到 95% 自動標成聽完，卡片打勾、標題變淡
- **佈景主題**：底部「設定」→「佈景主題」，三選一，點了立即套用
  - 訊號格（藍紫，預設）
  - 夜航（薄荷綠）
  - 琥珀電台（琥珀）
- **底部分頁**：音檔（Podcast／YouTube）、清單、待播、設定；目前都是空的說明畫面

## 開發中的功能

完整清單見 `docs/FEATURES.md`。主要包括：

- Podcast 分頁讀新知雷達的資料庫；YouTube 分頁接收分享、N100 自動抽音軌
- 背景播放（通知列、鎖定畫面、藍牙耳機）、倍速、單曲循環、睡眠計時、記住進度
- 桌面小工具（4×1、4×2、4×3）
- 播放清單、待播、搜尋、長按多選、垃圾桶
- 語音總控可以用講的操作（「播最新的 Podcast」「調成一點五倍速」）

## 常見問題

- **更新時顯示「與現有套件衝突」**：手上那支是不同簽章編譯的版本（例如本機 debug 版），要先解除安裝再裝；之後都用 GitHub 下載的版本就不會再發生
